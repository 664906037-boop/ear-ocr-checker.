# EAR Vehicle Checker — Consensus OCR V10

ปัญหาที่แก้:
เวอร์ชันก่อนใช้ OCR ค่าที่ดีที่สุดเพียงค่าเดียว แล้วเทียบตรง ๆ
ถ้า OCR อ่านเพี้ยน เอกสารที่จริง ๆ ตรงกันก็ถูกฟ้องว่าไม่ตรง

V10:
1. OCR แต่ละกรอบ 9 pass
2. ใช้ threshold หลายระดับ
3. เก็บ candidate หลายค่า ไม่ทิ้งเหลือค่าเดียว
4. เทียบ candidate ของ File 1 กับ File 2 ข้ามกัน
5. ถ้ามี candidate ที่ตรงกันจริง จะเลือกคู่นั้น
6. ถ้าค่าคล้ายกันมากแต่ OCR ยังแกว่ง จะขึ้น "OCR ไม่ชัวร์" แทน "ไม่ตรงกัน"
7. จะขึ้น "ไม่ตรงกัน" เมื่อ evidence ระหว่างสองไฟล์ต่างกันชัดจริง

ยังคงใช้ calibration boxes เดิมจาก V9 ใน localStorage ได้
